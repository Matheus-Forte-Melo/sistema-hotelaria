# Legado — Requisitos e UML da Etapa 1

Em 24/11/2026 a equipe concentrou a entrega no CRUD de reservas e na visualização temporal por andar. Estes arquivos preservam a especificação anterior, que incluía gestão de blocos, identificação e idade dos ocupantes, check-in, check-out, bloqueios por período e correções de histórico. Servem para interpretar a entrega acadêmica original e as entidades que já existiam no backend.
